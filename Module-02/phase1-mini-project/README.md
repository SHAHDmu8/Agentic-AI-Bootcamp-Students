# Module 2 — Phase 1 Mini-Project: Study Guide Agent

This project implements the same study-guide workflow twice:

- `study_guide_langgraph.py` uses a three-node LangGraph pipeline.
- `study_guide_crewai.py` uses one CrewAI agent with three sequential tasks.

The goal is to generate a beginner-friendly explanation, a practical example with a common misconception, and a three-question quiz with an answer key for a topic such as "Model Context Protocol" or "temperature in language models".

## Project overview

Both scripts operate on the same core idea:

1. explain the topic in plain language;
2. turn that explanation into a practical example and misconception;
3. assemble the final study guide with three quiz questions and matching answers.

Later tasks depend on earlier results, which is the main design challenge of the project.

## Setup

From the repository root, make sure the existing root `.env` file contains your OpenRouter API key:

```powershell
# Repository root
notepad .env
```

Then add:

```env
OPENROUTER_API_KEY=your_key_here
```

Do not print, expose, or commit the key. Keep it in the existing root `.env` file, not in a new project-local `.env` file.

## Engineering observations

1. LangGraph makes the data flow explicit. Each stage is a node, and the state handoff is visible in the graph structure.
2. CrewAI automates or hides some orchestration details. The sequential task chain and context passing are easier to declare, but the execution flow is less visually explicit.
3. For this three-task pipeline, LangGraph is preferable because the workflow is small, linear, and easy to reason about precisely; the state is explicit and each dependency is clear.
